# 計画書: アイコンをディスクと赤十字に変更 (v1.0)

## 要望

アプリのアイコンを、ディスクを背景にし、前面の右下へ赤十字マークを重ねた意匠へ変更する。

## 方針

- 既存のベクター原本 `assets/QuickDiskRescue-icon.svg` を、ディスク・プラッタと右下の赤十字バッジの構成へ更新する。
- SVG を高解像度でレンダリングし、Windows が選ぶ各サイズ（16 / 32 / 48 / 64 / 128 / 256 px）を含む ICO を生成する。
- GUI / CLI が参照する `core/native/QuickDiskRescue.ico` と配布用の `resources/icons/QuickDiskRescue.ico` を同一内容へ更新する。
- About 用の原本 `assets/QuickDiskRescue-icon.jpg` も新しい意匠へ更新する。

## 完了条件

- 実行ファイル用 ICO の全サイズに、背景のディスクと右下前面の赤十字が明瞭に表示される。
- ネイティブビルドが成功し、生成した EXE に新しいアイコンが埋め込まれる。
