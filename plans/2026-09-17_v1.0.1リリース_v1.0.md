# 計画書: v1.0.1 リリース (v1.0)

## 要望

QuickDiskRescue をバージョン 1.0.1 としてコミット、プッシュし、GitHub Release を公開する。

## 変更範囲

- CLI、Win32 リソース、マニフェスト、README、仕様書、About のバージョン表記を 1.0.1 に統一する。
- 変更履歴へ、ディスク背景と右下の赤十字バッジからなるアプリアイコン更新を記録する。
- リリース対象ブランチに含まれる NTFS ツリー解析／フォルダ救出の中止確認・進捗通知追加も変更履歴へ記録する。
- 既に作成済みのアイコン資産を含めてネイティブビルドを再実行する。
- GUI / CLI 実行ファイル、WebView2Loader.dll、README、変更履歴、ライセンスを含む Windows x64 向け ZIP を作成し、タグ `v1.0.1` の GitHub Release に添付する。

## 完了条件

- すべての製品バージョン表記が 1.0.1 で一致する。
- CLI の `--version`、GUI / CLI EXE の Windows バージョンリソース、既存テストが正常である。
- 対象変更のみをコミットして `origin/master` へプッシュし、公開済みの GitHub Release `v1.0.1` に ZIP を添付する。
