# 2026-09-09 出てくるのが C のフォルダではない 結果

原因: この PC の C: は BitLocker。生読みでは OEM が `-FVE-FS-` なので NTFS と見ず、残る NTFS は Recovery (約 2.4GB) だけだった。アプリはそれを開いていた。

対応:
- BitLocker / EFI / MSR / Recovery / Basic を区画に表示
- BitLocker 区画はツリーを出さず、暗号化のため読めないと出す
- Recovery を C の代わりに自動選択しない
- EXE 再ビルド済み

鍵なしの生読みで BitLocker の C: フォルダは出せない。ロック解除済みの `\\.\C:` 経由は別機能。
