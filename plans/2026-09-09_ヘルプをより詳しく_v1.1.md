# 計画書: ヘルプをより詳しく(v1.1)

## 目的
ヘルプメニューから、画面の見方・状態別の処置・ボタンの手順が読めるようにする。EXE に埋め込まれている本文が短い初版のままなので、実装済み機能だけを根拠に厚く書き、再ビルドする。

## 現状分析
- `resources/help/help_jp.md` / `help.md` は一度拡充済み。
- `dist/binary/index.html` と `core/native/index_embed.html` の `HELP_MD` は短い初版のまま（未バンドル）。
- `static/js/app.js` の `md()` は h1–h3・表・行頭 `-` のみ。番号リスト・強調・code はただの段落になる。

## 変更内容
- `resources/help/help_jp.md` / `help.md` を操作手順書として拡充する（実装済みの画面文言・エラーコードのみ）。
- `md()` に番号リスト、`**強調**`、`` `code` `` を追加する。
- ヘルプダイアログ幅を広げて表を読めるようにする。
- EXE に埋め込んで再ビルドする。

変更しないもの: エンジン、救出ロジック、未実装機能（BitLocker 復号、消失走査からの直接救出、ドライブレター割り当て）。

## 検証方法
- バンドル HTML の `HELP_MD.ja` に「状態と処置」「ステータスに出る文言」が含まれること。
- 番号リストが `<ol>` になること。

## リスク
ヘルプが長くなる。ダイアログは既存どおり縦スクロール。
