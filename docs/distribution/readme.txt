QuickDiskRescue v1.0.0
QuickDiskRescue v1.0.2

Rescue folders from unmounted disks. The source is never written.
Run QuickDiskRescue.exe elevated. Keep WebView2Loader.dll beside the EXE.

Integrity verification (SHA-256)
--------------------------------
Official SHA-256 checksums are automatically generated by the CI build and
published as SHA256SUMS.txt on each GitHub Release page. Verify with PowerShell:
  Get-FileHash .\QuickDiskRescue-binary.zip -Algorithm SHA256
