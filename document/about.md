# QuickDiskRescue about

## Version
Ver. v1.0.0

## Environment
- C++17 (MinGW-w64 / g++, WinLibs MCF UCRT)
- WebView2
- Win32 raw disk APIs (`CreateFile`, `FILE_FLAG_NO_BUFFERING`, storage/disk IOCTLs)

No third-party C++ libraries. The source disk is never written.
